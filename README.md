# Smart Clinic Appointment & Patient Management System (SCAPMS)

## Project Overview
The Smart Clinic Appointment & Patient Management System (SCAPMS) is a C++ desktop application developed using Qt for the Miva Open University Programming II Lab Assessment.

The system is designed to support basic clinic operations, including patient management, appointment scheduling, waiting queue management, patient searching and sorting, and report generation.

## Features

- **Patient Management:** Register, view, edit and delete patient records.
- **Appointment Management:** Schedule and cancel patient appointments.
- **Waiting Queue:** Manage patients using a First-In, First-Out (FIFO) queue.
- **Patient Searching:** Search patient records using linear, binary and recursive search techniques.
- **Sorting:** Organise patient records using selection sort, insertion sort and merge sort.
- **Reports:** Generate clinic reports, including patient category distribution, pending appointments and daily appointments.
- **Graphical User Interface:** A Qt-based interface with separate sections for the system's major functions.

1. Install Qt Creator and a compatible Qt development kit.
2. Download or clone this repository.
3. Open the project in Qt Creator using its `CMakeLists.txt` file.
4. Select a compatible compiler kit.
5. Configure and build the project.
6. Run the application.
